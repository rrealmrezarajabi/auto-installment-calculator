# ماشین‌حساب اقساط خودرو

یک صفحه فارسی و راست‌چین برای انتخاب خودرو یا ورود دستی، محاسبه آنی قسط و نمایش جدول اصل و سود. نمودار سهم اصل و سود، مقایسه دو مدت و اشتراک محاسبه با لینک هم پیاده شده‌اند.

با Next.js، React و TypeScript ساخته شده؛ ۱۲ خودرو با قیمت نمونه بازار و شرایط فروش ساختگی از API داخلی دریافت می‌شوند. قیمت‌ها از [car.ir](https://car.ir/prices) در ۱۶ آبان ۱۴۰۵ برداشته شده‌اند و خودکار به‌روز نمی‌شوند.

## اجرا

پیش‌نیاز: Node.js 24 و npm.

```bash
npm ci
npm run dev
```

صفحه را در [localhost:3000](http://localhost:3000) باز کنید.

برای اجرای نسخه تولید:

```bash
npm run build
npm start
```

## تست

```bash
npm test
```

تست‌ها شامل مثال دستی محاسبه قسط، گردکردن و جمع اصل‌ها، API و رفتارهای اصلی فرم، مقایسه و لینک اشتراک هستند. برای اجرای پیوسته از `npm run test:watch` و برای بررسی کد از `npm run lint` استفاده کنید.

## وضعیت

قابلیت‌های اصلی و هر سه مورد اختیاری تسک پیاده شده‌اند. 

فرض‌ها و روش رفع اختلاف گردکردن در [DECISIONS.md](./DECISIONS.md) آمده‌اند.
