# ماشین‌حساب اقساط خودرو

پروژه تمرینی با Next.js، React و TypeScript؛ داده‌های خودرو و شرایط فروش ساختگی‌اند.

## اجرا

با Node.js 24 و npm:

```bash
npm ci
npm run dev
```

صفحه در `http://localhost:3000` در دسترس است.

```bash
npm run build
npm start
```

## بررسی و تست

```bash
npm test
npm run test:watch
npm run lint
```

۳۳ تست متمرکز روی رفتارهای اصلی پروژه وجود دارد. تست‌های هر بخش در پوشه `__tests__` همان بخش قرار دارند. تست‌ها شامل قرارداد روت‌ها، اعتبارسنجی پاسخ API، کش و retry، محاسبات و گردکردن، تبدیل اعداد فارسی، تعاملات فرم و ۵ تست مهم نمودار، مقایسه و اشتراک هستند. تست‌های فرم در jsdom اجرا می‌شوند؛ جایگزین بازبینی بصری مرورگر نیستند.

## وضعیت فعلی

- دریافت خودروها از `GET /api/vehicles` و شرایط فروش از `GET /api/financing-options`.
- فرم فارسی و RTL با shadcn/ui، React Hook Form و Zod؛ انتخاب خودرو یا ورود دستی، پیش‌پرداخت و مدت اقساط.
- نمایش آنی قسط، مبلغ وام، مجموع سود و مجموع پرداختی؛ اعلان خطای API با Sonner و امکان تلاش مجدد.
- هسته مستقل محاسبه و جدول اقساط با اصلاح گردکردن در قسط آخر.
- نمایش جدول اقساط با اصل، سود، مانده وام و جمع کل؛ به‌روزرسانی آنی با فرم، اسکرول داخلی و توضیح قسط آخر.
- نمودار سهم اصل و سود از مجموع اقساط؛ پیش‌پرداخت در نمودار لحاظ نمی‌شود.
- مقایسه دو مدت بازپرداخت با شرایط خرید یکسان و امکان اعمال سناریو روی فرم و جدول.
- دکمه «کپی لینک محاسبه» برای اشتراک نام و قیمت خودرو، نرخ سود، پیش‌پرداخت، مدت و دو مدت مقایسه. لینک در پارامتر `calc` آدرس ذخیره می‌شود؛ هنگام بازشدن، مقادیر ذخیره‌شده بازیابی می‌شوند.
- در صورت رد دسترسی کلیپ‌بورد، لینک برای کپی دستی نمایش داده می‌شود. لینک نامعتبر با پیام مشخص به فرم پیش‌فرض برمی‌گردد.

فرض‌ها و سیاست گردکردن در `DECISIONS.md` ثبت شده‌اند.
